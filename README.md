# קורא PDF יומי

אפליקציית ווב מקומית לקריאת PDF בעברית ובאנגלית, עם גלילה רציפה, מצב ספר RTL/LTR, סימניות, שמירת מיקום, חיפוש, צילום מסך, הדגשות, מילוי טקסט וחתימה.

## הפעלה

השרת המקומי הופעל כרגע בכתובת:

```text
http://127.0.0.1:5173
```

להפעלה מחדש מתוך התיקייה:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

ואז לפתוח בדפדפן את `http://127.0.0.1:5173`.

אפשר גם ללחוץ פעמיים על:

```text
פתח_קורא_PDF.bat
```

## התקנה כאפליקציית ווב

פתח את האפליקציה ב-Chrome או Edge, ואז לחץ על "ברירת מחדל והתקנה" או השתמש בתפריט הדפדפן ובחר "התקן אפליקציה". לאחר ההתקנה האפליקציה תיפתח בחלון עצמאי עם אייקון.

## הערות

- הנתונים האישיים נשמרים ב-`localStorage` של הדפדפן לפי שם/גודל/תאריך הקובץ.
- ייצוא PDF צורב לתוך קובץ חדש את ההדגשות, שדות הטקסט והחתימות.
- דף ווב לא יכול לקבוע את עצמו כקורא ברירת מחדל של מערכת ההפעלה בלי פעולה ידנית מצד המשתמש. באפליקציה יש כפתור הסבר תחת "ברירת מחדל והתקנה".
- PDF.js, pdf-lib ו-html2canvas נטענים מ-CDN, לכן נדרש חיבור אינטרנט בעת פתיחת האפליקציה, אלא אם מורידים את הספריות ומעדכנים את הנתיבים מקומית.
